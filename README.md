# Тропа — траектория развития для детей 3–7 лет

Статическое веб-приложение без сервера: родитель заполняет анкету, система предлагает компетенции, профессии-ориентиры и навыки, строит траекторию по месяцам и даёт интерактивные упражнения с зачётами.

**Демо:** https://samber69.github.io/tropa/ · **ТЕСТ 1:** https://samber69.github.io/tropa/?test=1#/plan · **Образец PDF:** [samples/test1-program.pdf](samples/test1-program.pdf)

## Путь пользователя (CJM)

1. **Анкета** — возраст, способности (13 направлений × 4 уровня), физическое развитие, образование и профессии родителей, срок программы, часы в неделю.
2. **Рекомендации** — оценка 13 компетенций (0–100) с объяснением «почему», 13 профессий-ориентиров, навыки. Всё можно отметить или снять.
3. **Траектория** — этапы (Старт → Развитие → Мастерство → Финиш), календарь с вехами (запись в 1 класс, прослушивание в ДМШ, ярмарка), недельная нагрузка, роли родителей, кружки, ожидаемые результаты, итоговый проект. Кнопка **«Скачать PDF»**.
4. **Упражнения** — 33 навыка × 3 уровня. Уровень открывается после зачёта предыдущего. Задания озвучиваются (ребёнку не нужно читать).

## Типы упражнений

| Тип | Что делает ребёнок | Зачёт |
|---|---|---|
| Викторина (13 генераторов) | счёт, сравнение, состав числа, арифметика, закономерности, лишнее, фигуры, высота звука, монеты, прибыль, звуки, чтение, эмоции, живое/неживое, английский | 6 из 8 |
| Робот | программирует маршрут стрелками в лабиринте | 3 лабиринта |
| По порядку | алгоритмы, рассказ по картинкам, план дела | 2 из 4 с первой попытки |
| Пары | память и внимание | лимит ходов |
| Ритм | повторяет ритм на барабане | 3 из 5 |
| Мелодия | повторяет мелодию на 4 клавишах | длина 3/5/6 нот |
| Офлайн | спорт, конструирование, ярмарка, интервью | ставит взрослый (проверочный пример) |

## Как учитываются родители

Свободный текст об образовании («окончил МИРЭА», «МГУ, журфак») разбирается по ключевым словам в 10 сфер (`PARENT_DOMAINS` в `js/data.js`). Сфера добавляет баллы связанным компетенциям и даёт родителю роль в плане.

## Устройство

- `js/data.js` — справочники и методика (веса, навыки, задания, профессии, ТЕСТ 1).
- `js/engine.js` — оценки, траектория, прогресс (чистые функции).
- `js/exercises.js` — генераторы заданий и интерактивные раннеры.
- `js/pdf.js` — документ для pdfmake (подгружается с cdnjs по клику).
- `js/app.js` — экраны и роутинг (`#/intake`, `#/recommend`, `#/plan`, `#/learn`, `#/ex/<навык>/<уровень>`).

Данные и прогресс хранятся в `localStorage` браузера. `?test=1` загружает профиль ТЕСТ 1.

Запуск локально: любой статический сервер в корне, например `npx serve .`.
